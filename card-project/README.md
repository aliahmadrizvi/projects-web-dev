# 🎨 Card Project

A collection of responsive card designs built using **HTML** and **CSS**. This project was created to practice layouts, styling, hover effects, and responsive web design.

---

## 📂 Projects

### 🪪 Card 1
A simple profile card featuring:
- Clean layout
- Image
- Title & Description
- Responsive design
- CSS styling

**Files:**
- `index.html`
- `style.css`

---

### 🪪 Card 2
An improved modern card design with:
- Better UI
- Hover effects
- Responsive layout
- Modern typography
- Enhanced CSS styling

**Files:**
- `card2index.html`
- `card2.css`
